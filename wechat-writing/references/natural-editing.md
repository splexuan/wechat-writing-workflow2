# 自然化编辑

用于用户明确要求“去 AI 味”“更自然”“像我写的”，或终检发现明显机器模式的文章。目标是让表达更具体、自然并符合原有声口，不是规避检测，也不是把文章统一改成口语自媒体。

## 什么时候使用

- 用户明确要求自然化、降低机器感或匹配本人表达；
- 初稿存在成片空话、宣传腔、机械衔接、同构段落或公式化结尾；
- 翻译或生成稿语法正确，但中文语序和表达明显僵硬。

若问题实际是事实错误、论证缺环或结构混乱，先回到 [改稿](revision.md)。专业、克制、结构清楚本身不是 AI 味，不因“看起来太完整”而故意破坏。

## 诊断要有证据，也要检查例外

不要凭“感觉像 AI”修改。每个准备处理的问题都应能回答：

1. 原文哪一句或哪组段落出现了可指认的模式？
2. 它具体损害了准确性、理解、推进、节奏还是作者声口？
3. 删除、合并、改写或降级中，哪一种是最小修法？
4. 这个表达在当前文体中是否有合法功能？

找不到原文证据时，只把判断当作待观察的假设，不据此重写。步骤编号对教程有导航作用，对称结构可以承担对照，连接词可以标记真实转折，社群称呼在真实共同体中也可能自然；模式命中不等于必须删除。

## 先锁定不变量

编辑前标出并在完成后逐项回查：

- 数字、日期、专名、引语、来源和必要限定；
- 原文的立场、受众、文体和风险级别；
- 用户确认的经历、判断和必须保留的表达；
- 链接、引用、代码、表格及必要标题层级。

不新增人物、动作、感官、对话、数据、案例、来源、采访、动机或亲历。不把“不确定”改成确定，也不靠虚构细节让文字显得真实。

## 修改优先级

按影响从高到低处理：

1. **事实与归因**：假数据、模糊权威、把推断写成事实；
2. **内容空转**：夸大意义、宣传形容词、句尾伪分析、重复结论；
3. **公式结构**：假转折、强凑三项、段落同构、固定“挑战与展望”；
4. **表达节奏**：机械连接、同义词循环、抽象名词堆积、句长和句式过于一致；
5. **声口适配**：与作者档案、当前文体或目标读者明显不符。

先删没有信息的内容，再改仍然必要的句子。能改一个词就不重写一句，能删一句就不重写一段。

## 常见模式与最短修法

| 模式 | 判断信号 | 最短修法 |
|---|---|---|
| 夸大意义 | “标志着重要转折”“产生深远影响”但没有后果 | 写具体变化；没有就删除 |
| 宣传腔 | “开创性、卓越、无缝、令人惊叹” | 换成功能、动作、规模、时间或结果 |
| 模糊归因 | “专家认为”“业内指出”“研究表明” | 写明来源；无法确认就删除或降级 |
| 句尾伪分析 | “从而彰显”“进一步体现”“确保了” | 拆成可验证结果；无新增信息就删 |
| 机械连接 | 每段都以“此外、然而、因此、值得注意的是”起头 | 关系已清楚就删；不清楚则补真实关系 |
| 强凑三项 | 形容词、原因和建议总是三个 | 保留内容实际需要的数量 |
| 同义词循环 | 为避免重复不断替换同一对象的称谓 | 使用同一个准确称谓，合并重复句 |
| 虚假范围 | “从 A 到 B”两端不在同一尺度 | 列出实际范围或删除框架 |
| 协作残留 | “当然可以”“希望对你有帮助”“下面我们来” | 删除，直接进入文章 |
| 万能升华 | “未来可期”“让我们共同期待” | 写下一项事实、代价、未决问题，或直接结束 |

词语和标点本身不是错误。某个表达准确、自然并符合当前声口时可以保留，不执行黑名单清零。

诊断时还要区分“结构清楚”与“结构机械”：真正的问题是各节等长、同构、永远三点，或内容为了对称被强行切割；法律条文、操作清单和有意对照不适用这一判断。

## 检查假转折

遇到“不是 A，而是 B”或“不仅 A，更是 B”时逐项判断：

1. A 是否真有人主张，还是为了显得深刻临时制造的靶子？
2. A 与 B 是否其实同义，只是后者更抽象或更夸张？
3. 删除转折框架后，信息和逻辑是否完全不变？

若是假靶子，直接说 B；若 A 与 B 同义，合并成准确的一句；若没有真实转折，改成普通陈述。A、B 确实对立且澄清有价值时，保留原句式。

## 一轮编辑法

1. 锁定不变量并判断原文声口。
2. 删除空话、假权威和不能兑现的修辞。
3. 拆除公式结构，合并重复段落和同义句。
4. 把抽象表达落到原文已有的对象、动作、条件或结果。
5. 调整过于整齐的句段，但不为变化故意写乱。
6. 朗读通篇，修复生硬中文、注意力断点和与文体不符的语气。
7. 回查不变量，确认没有事实膨胀、立场漂移或新添经历。

默认只做一轮。第二轮仅处理第一轮引入的问题；若仍需大范围修改，说明问题属于结构或立论，应回到 `revision.md`，而不是继续反复“洗稿”。

## 中文句段的流动

- 句内优先承接读者已经知道的信息，再把新的、较重的信息放到后部；除非需要强调，不让陌生概念先悬空。
- 段内保持对象和话题连续，避免为了换词频繁更换主语、称谓或观察角度。
- 读者容易接受的内容可以直接给；需要较多证据、可能引起抵触的判断，先提供最低必要依据再落结论。
- 过渡首先来自前后句的真实关系。删除路牌式连接词后若逻辑断裂，应补清关系，而不是再换一个连接词。

这些是阅读路径，不是固定语序。倒装、跳接和省略确有强调或叙事功能时可以保留。

## 两个短例

**空话与模糊归因**

> 原句：这项规则把审核周期从企业自行安排改为每年一次。值得注意的是，多位专家认为，这项变化将对行业格局产生深远影响。  
> 修改：该规则把审核周期从企业自行安排改为每年一次。至于它是否会改变行业竞争，目前公开材料还不足以判断。

修改只保留原文已经给出的具体变化，删除无法归因的“专家认为”，并把无法证明的影响留在不确定状态；没有新增事实。

**机械连接与万能结尾**

> 原句：此外，整理完材料后还要进行复核。总之，只要坚持以上步骤，我们一定能够获得理想的结果。  
> 修改：整理完材料后再复核一次，重点检查日期、数字和遗漏项。到这里，这次整理才算完成。

教程的自然感来自动作和完成条件清楚，不需要额外加入个人故事、反问或情绪。

## 按文体保持声口

- **正式报道或事实梳理**：克制、清楚、归因明确；不注入第一人称和表演性情绪。
- **评论或行业专栏**：可以锋利和有个人判断，但情绪必须落在事实、机制或代价上。
- **教程或技术说明**：直接、准确、少铺垫；步骤需要编号时保留，不为自然感打乱顺序。
- **复盘**：保留当时与事后的时间差，不把过程改写成事后看来必然正确。
- **随笔**：保护作者原有节奏和留白；不把含混体验自动总结成方法论。

若已有 `author-profile.md` 或相关稳定风格规则，按 [风格学习](style-learning.md) 选择少量适用规则；不要让人设覆盖本文任务。

## 输出与停止条件

默认只交付编辑后的完整文字。用户要求说明时，再附 1—3 个最高影响的修改点；不默认输出 AI 味等级、命中数量、长检查表或逐句分析。

满足以下条件即停止：信息没有缩水或膨胀；事实、立场和限定未变；明显机器模式已不再妨碍阅读；继续修改只会换一种说法而不会提高准确性或自然度。最后转入 [审校](review.md) 做事实和改动副作用检查。
