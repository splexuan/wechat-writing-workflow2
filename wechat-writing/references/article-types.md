# 文体选择

用于决定一篇文章主要怎样完成任务。文体影响读者收益、证据负担和结构，不是固定格式；一篇文章可含其他元素，但只保留一种主结构。

## 快速选择

| 读者主要问题 | 推荐主文体 | 核心交付 |
|---|---|---|
| “这件事到底意味着什么？” | 解释或热点分析 | 事实线、机制与影响 |
| “你为什么这样判断？” | 评论或观点 | 有边界的论点与反方处理 |
| “我该怎么做？” | 教程或问题解决 | 可执行步骤、条件与避坑 |
| “我该选哪个？” | 对比或决策 | 标准、权衡和条件式推荐 |
| “这次经历说明了什么？” | 故事或复盘 | 真实过程、选择、结果与可迁移认识 |
| “这种感受怎么理解？” | 随笔 | 具体经验与更准确的表达 |

如果文章同时想完成三种主要任务，通常需要缩题，而不是把三套结构叠在一起。

## 解释与热点分析

适合事件、技术、行业变化和公共议题。

常用推进：发生了什么 → 真正需要解释的问题 → 背后机制 → 谁受到什么影响 → 容易误读什么 → 继续观察什么。

写作重点：

- 先分清已发生、已宣布、被预测和仍未知；
- 不按新闻时间线机械复述，围绕一个解释问题组织事实；
- 热点之外提供背景比例和比较基准；
- 结尾可以给观察指标，不必强行提供行动清单。

常见失败：标题比事实更确定；用单一原因解释复杂变化；把短期关注度写成长远趋势。

## 评论与观点

适合价值判断、公共讨论和对常见说法的修正。

常用推进：明确命题 → 说明常见理解为何不够 → 给出事实和推理 → 处理最强反方 → 限定结论 → 回到读者现实。

写作重点：

- 尽早亮出真正判断，避免全文只铺垫不表态；
- 区分事实判断、因果解释和价值选择；
- 把反方写到其支持者也愿意承认的程度；
- 结论可以鲜明，但范围不能超过材料。

常见失败：为反常识而反常识；把情绪强度当论证；先决定结论再选择性找证据。

## 教程与问题解决

适合工具、方法、流程和具体困扰。

常用推进：使用场景 → 目标和前提 → 步骤或原则 → 示例 → 验证方法 → 常见错误与不适用情况。

写作重点：

- 明确读者起点、需要准备什么、什么算完成；
- 步骤写动作和判断条件，不只写抽象建议；
- 对关键分支说明“如果……那么……”；
- 提供验证结果的方法，而不是以“操作完成”代替有效。

常见失败：步骤缺前提；把个人习惯包装成唯一方法；清单很多但读者仍不知道怎么判断下一步。

## 对比与决策

适合产品、方法、方案和路径选择。

常用推进：明确选择情境 → 设定比较标准 → 按标准逐项比较 → 呈现代价 → 按条件推荐 → 说明不适用对象。

写作重点：

- 先说为谁、为哪个目标比较；
- 标准应来自读者决策，不是来自容易找到的数据；
- 同一维度使用相近材料和口径；
- 推荐写成条件组合，避免伪装成普遍最优。

常见失败：标准中途改变；只罗列功能没有权衡；把合作或偏好隐藏成客观结论。

## 故事与复盘

适合真实经历、项目、选择和失败经验。

常用推进：背景与目标 → 初始判断 → 关键选择 → 摩擦与代价 → 转折 → 结果 → 哪些认识可迁移。

写作重点：

- 只用用户提供或确认的真实细节；
- 选择真正改变结果的节点，不做完整流水账；
- 区分当时知道什么和事后才看懂什么；
- 可迁移结论应保留案例条件，不从一次经历推出万能规律。

常见失败：虚构对话和感官细节；事后把过程写得过于必然；只讲成功结果，删掉关键代价。

## 随笔

适合生活片段、关系、情绪、阅读触发和个人观察。

常用推进没有固定顺序，可从一个具体片段、困惑或矛盾开始，在联想和思考中逐步抵达更准确的感受或判断。

写作重点：

- 具体来自真实材料，不用虚构细节换取“有画面”；
- 保留作者声音和未完全解决的张力；
- 联想必须推进认识，不以漂亮句子替代内容；
- 结尾可以开放、克制，不必总结成方法论或积极口号。

常见失败：把私人感受包装成社会定律；每个片段都急着上价值；为了自然故意松散或跳跃。

## 混合文体的控制

- 教程中的故事只负责说明问题，不抢走操作主线。
- 评论中的热点事实只负责支撑判断，不变成新闻汇编。
- 复盘中的方法只来自已展示的选择和结果，不突然增加万能清单。
- 随笔中的研究只补足必要事实，不压过个人观察。

选定主文体后直接进入 [写作与成稿](drafting.md)。只有评论、解释或热点分析确实需要形成争议性判断时，才先读取 [论证与提纲](argument.md)；教程、复盘和随笔不为了流程完整而强行立论。
