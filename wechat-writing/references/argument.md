# 论证与提纲

用于评论、解释、热点分析和需要深度改稿的文章。目标是围绕一个真实问题组织事实、解释和作者判断，而不是把资料依次排进章节。教程、操作指南、单纯叙事和随笔只有在确实需要立论时才读取本文件。

## 中心论点测试

合格的中心论点通常是一句完整判断，并同时满足：

- 回答读者真正的问题，不只是复述主题；
- 有人可能合理地不同意，因此需要论证；
- 对象、时期、条件和确定性与证据相称；
- 能统领全文，能判断每一节为什么存在；
- 提供新增解释、判断标准、被忽略的代价或更准确的边界。

“本文讨论人工智能对写作的影响”是主题；“生成工具降低了成稿成本，但把写作者的稀缺能力推向选题、判断与核验”才是可论证的判断。

如果一句话只能靠“所有人、必然、彻底、颠覆”等词显得有力，先检查是否应缩小范围。

## 论证简报

写提纲前在内部回答：

1. 读者现在可能怎么理解这件事？
2. 本文准备改变哪一个判断？
3. 支撑中心论点的 2—4 个分论点是什么？
4. 每个分论点分别依赖事实、机制、案例还是价值判断？
5. 最强竞争解释是什么，它解释得比本文更好的部分有哪些？
6. 中心论点在哪些条件下不成立？
7. 读完后，读者获得的是新事实、解释模型、选择标准还是表达自己感受的语言？

这些内容用于组织写作，不要把问题清单原样放进正文。

## 先搭最短论证链

评论和分析文章在列章节前，先写出让中心论点成立所需的最少步骤，例如：

```text
具体现象 → 需要修正的常见理解 → 唯一主解释 → 关键证据 → 必要边界
```

这只是关系示意，不要求每篇都写成五段。删去某一步后若读者仍能理解并接受结论，就继续删；若需要新增一步，必须说明它补的是推理缺口、证据缺口还是边界。不要用“更全面”作为增加章节的理由。

一篇文章可以承认多种因素，但正文只展开一条主解释。其他解释只能承担三种职责：补主解释的缺口、作为竞争解释施加压力、限定结论的适用范围。另一套解释若需要独立背景和完整因果链，只留与本文直接相关的一句，或另存选题。

材料较多时，在内部做一次最小准入检查：

| 材料 | 对应哪一步 | 论证职责 | 删除会损失什么 | 处理 |
|---|---|---|---|---|
| 数字、案例或背景 | 最短论证链中的具体一步 | 前提 / 证据 / 解释 / 反例 / 边界 | 可明确说出的损失 | 保留 / 一句带过 / 删除 |

“内容会少一点”“文章没那么丰富”不算损失。材料真实、精彩或已经核实，也不能替代论证职责。

## 搭建主张链

每个关键段落尽量完成一种清晰关系：

```text
材料或现象 → 解释 → 中间判断 → 对中心论点的作用
```

检查容易跳步的位置：

- 从“同时发生”跳到“前者导致后者”；
- 从“能做到”跳到“会普遍采用”；
- 从“一个案例”跳到“一类人都如此”；
- 从“描述现状”跳到“因此应该怎样”；
- 从“某方有动机”跳到“某方一定出于该动机”。

需要补证就回到研究；缺乏材料时，改成可能性、条件式判断或开放问题。

## 切面划分与主次

中心论点需要多个切面支撑时，先做两件事：区分职责，再判断轻重。这是帮助发现重复和失焦的诊断方法，不是每篇文章都必须套用的结构。

### 区分：每个切面承担不同的论证任务

| 切法 | 示例 |
|---|---|
| 按维度 | 法律上 / 社会评价上 / 家庭接受上，是三个不同的问题 |
| 按归因 | 审美因素 / 历史因素 / 传播因素 |
| 按范围 | 哺乳动物 / 动物界 / 现存生命 / 全部生命史 |
| 按时间 | 周 / 秦汉 / 唐宋 / 明清 |

切面可以在现实中相互影响，也可以共享少量背景材料；关键是各自推进的问题不同。自检时问：删掉其中一个，论证会失去哪一步？如果两个切面依赖同一批证据、推出同一层结论，通常应合并；如果它们分别解释机制、影响或边界，则不必为了“零交集”强行拆开。

### 定轻重：需要主线时，不要把所有切面写成同样分量

评论、解释和热点分析通常需要一个明显主推进，让读者知道“到底哪一点最重要”。教程的并列步骤、对比文章的同口径维度、复盘的关键节点和随笔的多线联想可以相对均衡，不应为了制造主次破坏任务本身。

- 主推进应获得足够篇幅完成关键机制、证据或判断；50%—60% 可作为评论和解释文章失焦时的诊断参考，不是验收线；
- 其余切面只做两件事：为它补上缺口，或给它施加压力；
- 允许某些切面明显更短；短的切面只要完成了限定、反例或补充任务，就不削弱完整度。

主推进之外的一切，都要能回答：它为那个判断做了什么。

### 成稿后在失焦时再检查分布

提纲上的主次和成稿实际分布经常不一致。最容易被写厚的往往是“处理反方”和“补充证据”——它们每一处单看都必要，合起来却可能削弱主线。主推进也可能因为作者太熟悉而没有展开。

先让目标读者尝试用一句话复述文章新增了什么。只有出现“记住几个并列点，却说不出哪个最重要”的失焦症状时，再按节估算或统计篇幅，检查主推进是否被配角挤压；不要把比例本身当成质量结论。

补救方向通常不是删反方——反方提供文章的诚实度和边界。要回到主推进，检查最关键的机制是否展开、证据是否足够，或是否缺少能串起整条线的案例。若文章本来就是教程、对比或随笔，则回到对应文体的任务判断，不套用主推进比例。

## 认真处理反方

反方不是为了让文章显得客观而插入的一句“当然也有人认为”。优先寻找：

- 能解释同一批事实的另一套机制；
- 结论相反但证据质量相当的材料；
- 文章结论不适用的人群、时期或场景；
- 即使中心判断成立，也必须付出的代价。

处理反方有四种诚实结果：吸收进主论点、限定结论、说明为何证据仍不足，或承认文章当前无法裁决。不要制造一个明显愚蠢的观点再轻易驳倒。

## 原创性从哪里来

不必故意反常识。可用的新增价值包括：

- 把几个零散事实放进同一个因果或激励框架；
- 指出常见说法成立所缺少的条件；
- 区分经常被混为一谈的对象、时间尺度或评价标准；
- 找到被多数讨论忽略的成本、受影响者或二阶后果；
- 把抽象争论还原成读者可使用的判断标准；
- 用真实个人材料说明一种体验，但不把它外推为普遍规律。

若没有新增价值，宁可做清楚的事实梳理或实用指南，不强造惊人结论。

## 把论证变成提纲

提纲不是资料分类。每一节用一句“本节完成什么推进”来命名：

| 位置 | 要完成的任务 |
|---|---|
| 开头 | 建立具体问题、冲突或需要修正的理解 |
| 第一推进 | 给读者理解后文所需的事实或概念 |
| 核心推进 | 展开最关键的机制、证据或判断 |
| 压力测试 | 处理竞争解释、反例、代价或边界 |
| 结尾 | 回答最初问题，并给出与题材相称的读者收益 |

不必每篇都有五部分，也不要求按这个顺序。判断每一节：删掉后，中心论点会失去哪一环？若答案只是“少一点丰富”，该节可能只是旁枝。

## 提纲通过门槛

写正文前逐项检查：

- **同层比较**：并列章节必须使用同一种划分口径。组织单位、人物记忆和文本结构不能直接并列，应改成共同上位维度再比较。
- **一节一职**：每节只承担一个主要推进；同时解释机制、扩展历史又讨论影响时，应拆分或确定主次。
- **去重合并**：两节若依赖同一批材料并推出同一层结论，合并；标题不同不算职责不同。
- **单一主解释**：正文只展开一条主解释；其他机制只能补缺、施压或限定，不能各自扩成平行文章。
- **材料准入**：每项数据、案例和背景都能指出对应步骤与删除损失；只增加丰富度的材料不进入正文。
- **旁枝止步**：某节若提出了另一篇文章才能回答的新核心问题，只保留与本文结论直接相关的一句，其余删除或另存选题。
- **结尾不加料**：结尾只能收束正文已经展开的判断、边界或行动，不加入新证据、新概念和新论证分支。

以上任一不满足，不进入正文。

若主文体尚未确定，再读取 [文体选择](article-types.md)；已经明确是评论或解释文章时，直接进入 [写作与成稿](drafting.md)，不要在两个参考之间往返。

提纲完成后，若文章需要面向作者读者圈之外的陌生人争取理解与转述，额外读取 [锐化手法](sharpening.md)，处理专名密度与反方落点；个人随笔、复盘和篇幅较短的说明文不需要。
